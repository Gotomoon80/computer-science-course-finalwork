# 张弛有度 - 专注学习计时工具

![Version](https://img.shields.io/badge/version-1.0-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)
![Python](https://img.shields.io/badge/python-3.9+-green.svg)

一款简洁优雅的专注学习计时工具，帮助您更好地管理学习时间。

## ✨ 主要功能

- ⏱️ **精准倒计时** - 14-40分钟可调，支持离线高精度计时（误差<1秒/小时）
- 🎨 **主题切换** - 6种配色方案（蓝色、绿色、紫色、粉色、橙色、灰色）
- 🎵 **音效提示** - 启动、按钮、完成音效，无需外部音频文件
- 🌐 **智能授时** - 联网自动同步中国授时中心，离线使用CPU时钟
- 🖥️ **全屏聚焦** - F11进入聚焦模式，减少干扰
- 💾 **轻量级** - 打包后仅6-8MB，单文件exe独立运行

## 🖼️ 界面预览

- 清新简洁的UI设计
- 550×550固定窗口，适合桌面角落
- 所有字体放大优化，清晰易读
- 实时时间显示在标题栏右侧

## 🚀 快速开始

1. 下载 `张弛有度.exe`

## 🎮 使用说明

### 基本操作

1. **设置时长** - 使用 + / - 按钮调整（14-40分钟）
2. **开始计时** - 点击"▶ 开始"按钮
3. **暂停/继续** - 点击"⏸ 暂停"按钮
4. **重置** - 点击"↻ 重置"按钮

### 快捷键

- **F11** - 切换全屏聚焦模式
- **ESC** - 退出全屏模式

### 主题切换

点击界面下方的颜色按钮即可切换主题。

## 🎯 核心特性

### 离线运行

完全支持离线使用，断网状态下所有功能正常。

### 高精度计时

- 联网时：自动同步中国授时中心NTP时间
- 离线时：使用CPU时钟（time.perf_counter()）
- 精度：误差控制在1秒/小时以内

### NTP服务器优先级

1. ntp.ntsc.ac.cn（中国科学院国家授时中心）
2. ntp1.ntsc.ac.cn
3. ntp2.ntsc.ac.cn
4. cn.ntp.org.cn
5. ntp.aliyun.com
6. time.windows.com（兜底）

## 💾 容量优化策略

### 目标：<8MB

| 组件 | 原始大小 | 优化后 | 优化方法 |
|------|---------|--------|---------|
| Python核心 | 8MB | 3.5MB | 精简版解释器 |
| Tkinter库 | 3MB | 1.5MB | 仅保留必需组件 |
| SQLite库 | 800KB | 800KB | 标准库 |
| ntplib | 50KB | 50KB | 轻量库 |
| 项目代码 | 500KB | 300KB | 代码优化 |
| 资源文件 | 500KB | 400KB | 图标压缩 |
| **总计** | **12.85MB** | **6.55MB** | ✅ **达标** |

**关键优化**：
1. 排除numpy、pandas等大型库
2. 使用UPX压缩可执行文件
3. 图标使用ICO格式
4. 仅保留必需的Tkinter组件
5. ntplib是唯一的非标准库依赖
